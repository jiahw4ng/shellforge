Unix is a family of operating systems and a set of ideas for working with a
computer. It became popular because it is built from many small programs that
can be combined to do useful work.

Linux is a Unix-like operating system. More precisely, Linux is the kernel:
the part that manages the computer's hardware and lets programs run. A Linux
distribution, such as Ubuntu or Debian, combines that kernel with programs,
tools, and settings to make a complete operating system.

Shellforge gives you a Linux environment. The commands you learn here follow
the Unix way of working, so many of them also work on other Unix-like systems
such as macOS.

## A useful distinction

- **Unix** is the original family and set of design ideas.
- **Linux** is a Unix-like kernel and the basis for many operating systems.
- A **Linux distribution** packages Linux with the rest of a usable system.
