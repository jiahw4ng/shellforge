A **shell** is a program that reads commands, runs programs, and prints their
output. It is the text-based interface between you and the operating system.

The terminal is the window you see. The shell is the program running inside
that window. When you type a command and press Enter, the terminal sends it to
the shell; the shell decides what to run and shows the result in the terminal.

Try sending text to the shell:

```bash
echo "Hello, shell!"
```

`echo` is a small program that prints the text you give it. This simple
command demonstrates the usual flow: you type a command, the shell runs it,
and the terminal displays its output.
