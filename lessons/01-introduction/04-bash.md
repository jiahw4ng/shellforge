There are several kinds of shells. **Bash** is one of the most common shells
on Linux. Its name means **Bourne Again SHell**: it was designed as a
compatible successor to an older shell called `sh`.

Bash understands commands such as `echo`, can remember variables, run scripts,
and combine programs. Shellforge starts a Bash session for you, so the commands
in these lessons use Bash syntax.

To see the shell for this session, run:

```bash
echo "$0"
```

You should see `bash`. Later, you will use Bash to move through directories,
create files, and connect small commands into larger tasks.
