`ls` lists the files and directories in your current directory.

```bash
ls
```

Useful flags:

- `-a` includes hidden names such as `.config`.
- `-A` includes hidden names except `.` and `..`.
- `-l` uses a detailed, one-item-per-line view.
- `-h` makes sizes easier to read; combine it with `-l` as `ls -lh`.
- `-t` sorts by newest modification time; `-S` sorts by size.
- `-r` reverses the selected sort order.
- `-R` lists subdirectories recursively.
- `-d` describes a directory itself instead of listing its contents.

Flags can be combined: `ls -lah`. Run `ls --help` or `man ls` for GNU ls’s
complete reference.
