`cd` means “change directory”. It changes where subsequent commands run.

```bash
cd project
cd docs
cd ..
cd /home/student/workspace
cd
```

`cd` with no arguments returns you to your home directory.

`..` means the parent directory. An absolute path begins with `/`; a relative
path begins from your current directory.
